# 🎨 Telegram AI-бот «Центр Красок #1»

AI-ассистент для Telegram, отвечающий на вопросы о магазине [centr-krasok.kz](https://centr-krasok.kz) на основе структурированной базы знаний.

---

## Архитектура

```
Пользователь (Telegram)
        │
        ▼
  python-telegram-bot  ←── polling / webhook
        │
        ▼
    bot.py (хендлеры)
        │
   ┌────┴────┐
   │         │
guard()   get_ai_response()
(фильтры)      │
               ▼
       Anthropic Claude API
       (claude-sonnet-4)
               │
       System Prompt + База знаний
       + История диалога (10 сообщений)
               │
               ▼
          Ответ пользователю
```

## Быстрый старт

### 1. Получите токены

**Telegram Bot Token:**
```
1. Откройте @BotFather в Telegram
2. Отправьте /newbot
3. Следуйте инструкциям → получите токен вида: 123456:ABC-DEF...
```

**Anthropic API Key:**
```
1. Зарегистрируйтесь на console.anthropic.com
2. Перейдите в API Keys → Create Key
3. Скопируйте ключ вида: sk-ant-...
```

### 2. Настройте переменные окружения

```bash
cp .env.example .env
# Откройте .env и заполните:
# TELEGRAM_BOT_TOKEN=ваш_токен
# ANTHROPIC_API_KEY=ваш_ключ
```

### 3а. Запуск через Docker (рекомендуется)

```bash
docker compose up -d
```

### 3б. Запуск локально

```bash
# Python 3.11+
pip install -r requirements.txt

export TELEGRAM_BOT_TOKEN="ваш_токен"
export ANTHROPIC_API_KEY="ваш_ключ"

python bot.py
```

## База знаний

Файл `company_knowledge.py` содержит структурированную информацию о компании:

- О компании (миссия, преимущества, юр. данные)
- Контакты и адреса (Алматы, Астана)
- Полный каталог продукции по категориям
- Все бренды (~40+ брендов)
- Услуги (колеровка, доставка, консультации)
- Условия для дизайнеров и строителей
- Клиенты компании
- Примеры цен

**Обновление базы знаний:** просто отредактируйте `COMPANY_KNOWLEDGE` в файле `company_knowledge.py` и перезапустите бота.

---

## Защита от галлюцинаций

Бот защищён несколькими уровнями:

1. **System Prompt** — строго предписывает отвечать только по базе знаний
2. **Явный запрет выдумывать** — если информации нет, бот говорит об этом
3. **Guard фильтр** — блокирует нерелевантные/вредоносные темы до обращения к AI
4. **Направление к живому менеджеру** — при отсутствии данных даёт контакты компании

## Ограничения и стоимость

- **Модель:** `claude-sonnet-4-20250514`
- **История:** последние 10 сообщений на пользователя (in-memory, сбрасывается при рестарте)
- **Стоимость:** ~$0.003 за типичный диалог (Sonnet)
